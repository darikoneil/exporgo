# Local skills (yours)

Skills in this folder belong to this project and are **never touched by `exporgo update`**.
Put project-specific procedures here; author them from `templates/SKILL.template.md`
(one folder per skill, `SKILL.md` inside) and register them in `SKILLS.md` under "Local skills".

Anything reusable across projects belongs upstream instead: add it to the template repo's
`.claude/skills/exporgo/` so every project receives it on the next `exporgo update`.
