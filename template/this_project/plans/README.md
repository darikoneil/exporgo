# Plans

Forward-looking work: aims not yet started, ideas worth keeping, timelines, and roadmaps. This is
the project's thinking space, distinct from `experiments/`.

The line between the two: **`plans/` is what you intend to do; `experiments/` is what you are doing
or have done.** When a plan becomes real, copy `experiments/_TEMPLATE/` into a new experiment
folder and move the relevant notes across. A plan that has been executed either becomes an
experiment or is archived here with a note pointing to where it went.

## What belongs here

- **Aims / ideas** — candidate experiments and directions, with enough detail to pick them up later.
- **Timelines** — milestones, deadlines, order of operations.
- **Roadmaps** — how the aims fit together into a paper or a grant.

Free-form is fine — one file per idea, or a single `roadmap.md`. Keep speculative material here so
it doesn't clutter the experiments that are actually running.
