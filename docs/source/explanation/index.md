# Explanation

Explanation is understanding-oriented. These pages step back from any single task to describe
how exporgo thinks: the identity model and its coordinate keys, the five component kinds and how
to choose among them, closed-world versus open-world membership, why the filesystem is the source
of truth, how the logging, study, and datastore layers fit together, and how the storage model
behaves under concurrent, multi-user access.
