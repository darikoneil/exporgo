# Explanation

Explanation is understanding-oriented. These pages step back from any single task to describe
how exporgo thinks: the identity model and its coordinate keys, the four component kinds and how
to choose among them, and the layered architecture that meets the workspace CLI at the data root.
They also cover closed-world versus open-world membership, why the filesystem is the source of
truth, and how the storage model behaves under concurrent, multi-user access.
