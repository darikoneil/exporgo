# Tutorials

Tutorials are learning-oriented. Each one walks you end to end through a single happy path,
from a blank directory to a working result, so you can build a mental model of exporgo by
doing.

Start with the walkthrough: declaring a study, registering identities, pointing at resources,
storing data, and validating what's on disk.
